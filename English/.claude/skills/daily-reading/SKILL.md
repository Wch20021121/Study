# Daily Reading - 考研英语阅读理解文章生成

## 概述

本技能用于生成考研英语一（English I）风格的阅读理解文章。每篇文章模拟真实考研阅读难度（约400-500词），包含学术性话题、复杂句式和考研核心词汇，并配有5道选择题（涵盖词义推断、细节理解、推理判断、主旨大意、观点态度等题型）。

## 工作流

### 第1步：确定话题与日期

1. 确认目标月份和日期（如 5月6日 → `5-6.json`）
2. 选择话题：优先选择科技、经济、环保、教育、健康、文化等考研高频话题
3. 确认 `READ/data/<month>/` 目录存在，若不存在则创建

### 第2步：撰写文章

**格式要求：**
- 3-5段，用 `\n\n` 分隔
- 全文约 400-500 词
- 学术性、议论性风格，包含复杂句式（定语从句、状语从句、倒装等）
- 包含考研核心词汇（如 proliferation, scrutiny, substantiate, pervasive 等）

**段落结构：**
- 第1段：引入话题，提出核心观点或现象
- 第2-3段：展开论证，引用研究、数据、专家观点
- 第4-5段：深入分析影响、意义或对策

### 第3步：生成题目

生成5道选择题，每题4个选项（A/B/C/D），必须包含：

**题型分布：**
- 1道词义推断题（Word Meaning）
- 1-2道细节理解题（Detail Comprehension）
- 1道推理判断题（Inference）
- 1道主旨大意题或观点态度题（Main Idea / Author's Attitude）

**每题必须包含：**
- `num`：题号（1-5）
- `type`：题型（中文）
- `stem`：题干（含题号）
- `options`：4个选项的数组
- `answer`：正确答案字母（A/B/C/D）
- `explanation`：完整解析对象，包含 A/B/C/D 四个选项的解释（中文）

**explanation 格式示例：**
```json
"explanation": {
  "A": "正确。[解释为什么正确，引用文中依据]。",
  "B": "错误。[解释为什么错误]。",
  "C": "错误。[解释为什么错误]。",
  "D": "错误。[解释为什么错误]。"
}
```

### 第4步：答案复检

生成所有题目后，必须自我检查：
1. 每题答案是否唯一确定？
2. 解析是否与文中信息一致？
3. 干扰项是否具有合理的迷惑性？
4. 正确答案是否有明确的文中依据？

### 第5步：标注单词

从文章中提取 20-30 个考研重难点单词，格式为对象数组：

```json
"words": [
  {"word": "proliferation", "def": "激增，扩散"},
  {"word": "scrutiny", "def": "审查，仔细检查"}
]
```

**单词筛选原则：**
- 优先选择考研高频词、熟词僻义、学术词汇
- 每个单词翻译必须准确（参考主流词典）
- 按在文中出现顺序排列

### 第6步：保存 JSON

文件路径：`READ/data/<month>/<day>.json`

**JSON 结构：**
```json
{
  "date": "<month>/<day>",
  "month": <month>,
  "day": <day>,
  "title": "Article from <month>/<day>",
  "text": "<3-5段文章，\\n\\n分隔>",
  "questions": [ /* 5道题 */ ],
  "words": [ /* 20-30个单词 */ ]
}
```

### 第7步：构建与验证

```bash
python3 temp/build.py
```

检查构建输出：
- 若输出 `✅ 构建完成，所有验证通过！` → 完成
- 若输出 `⚠️ 发现以下问题` → 必须修复所有问题后重新构建

**常见问题及修复：**
- "段落数不足" → 确保 text 中至少有3段（用 `\n\n` 分隔）
- "题目数量不为5" → 确保 questions 数组恰好有5个元素
- "缺少答案" → 检查每题 answer 字段
- "缺少解析" → 检查每题 explanation 对象，确保 A/B/C/D 都有内容且不为 "N/A"
- "重点单词过少" → 确保 words 数组至少20个元素

### 第8步：单词翻译核验

生成文章后，重新检查 words 数组中每个单词的翻译是否准确，特别是：
- 熟词僻义（如 spring 作"弹簧；涌现"义）
- 学术语境中的专业含义
- 短语动词的准确翻译
