01

LINEAR ALGEBRA

线性代数

判定 · 秩 · 合同

行向量组等价

A、B 同列数

两组向量可以互相线性表出。

Ax=0 与 Bx=0 同解 ⇔ A、B 行向量组等价

⚠️ 同解 ⇒ 等价，不是向量组相等。

列向量组等价

A、B 同行数

转置后看零空间，结论与行情形对称。

A、B 列向量组等价 ⇔ ATx=0 与 BTx=0 同解

方阵结论

A 为方阵
r(A)=r(A²)⇔ Ax=0 与 A²x=0 同解⇔ A 与 A² 行向量组等价

伴随矩阵的秩 r(A*)

按 r(A) 分三档
r(A)=n→r(A*)=n
r(A)=n−1→r(A*)=1
r(A)≤n−2→r(A*)=0

相似 / 合同 / 正交相似

看变换矩阵
P⁻¹AP=B相似保特征值
PᵀAP=B合同P 可逆；保正负惯性指数
QᵀAQ=B正交相似Q 正交，Qᵀ=Q⁻¹；同时相似 + 合同

实对称矩阵：合同 ⇔ 正负惯性指数相同；合同不一定相似；相似一定合同。

正定矩阵判定

任选一条即可
  • 顺序主子式全 > 0
  • 特征值全 > 0
  • 存在可逆矩阵 C，使 A=CᵀC
02

PROBABILITY & STATISTICS

概率论与数理统计

分布 · 卷积 · 数字特征

二维正态分布

五个参数

(X,Y) ~ N(μ₁, μ₂, σ₁², σ₂², ρ)

f(x,y) = 1 / [ 2π σ₁ σ₂ √(1−ρ²) ]
         · exp{ −1/[2(1−ρ²)] · [
             ((x−μ₁)/σ₁)²
             − 2ρ·((x−μ₁)/σ₁)·((y−μ₂)/σ₂)
             + ((y−μ₂)/σ₂)²
           ] }

ρ=0 时交叉项消失；二维正态下，独立 ⇔ 不相关。

⚠️ 边缘都是正态，联合不一定是二维正态。

二维连续型：边缘与条件

积分限 −∞ 到 +∞
fX(x) = ∫ f(x,y) dy
fY(y) = ∫ f(x,y) dx
fX|Y(x|y) = f(x,y) / fY(y)

条件密度要求 fY(y) > 0。

Z=X+Y 与极值分布

卷积 / 极值
fZ(z) = ∫ f(x, z−x) dx

卷积公式，积分限 −∞ 到 +∞；独立时 f(x, z−x) = fX(x)·fY(z−x)。

下面两条 max / min 分布要求 X、Y 独立。

Fmax(z) = FX(z) · FY(z)
Fmin(z) = 1 − [1−FX(z)]·[1−FY(z)]

协方差与相关系数

数字特征
Cov(X,Y) = E(XY) − E(X)E(Y)
ρXY = Cov(X,Y) / [ √D(X) · √D(Y) ]
D(X±Y) = D(X) + D(Y) ± 2Cov(X,Y)

独立 ⇒ 不相关；一般不相关推不出独立，仅二维正态等价。

统计冷门结论

考前扫一眼
  • 辛钦大数定律：独立同分布、期望存在，不需要方差存在。
  • F(1−α)(n₁,n₂) = 1 / Fα(n₂,n₁)

CALCULUS · MATH I ONLY

高等数学（数一专属）

场论 · 方程 · 几何

梯度、散度、旋度

场论
grad u = ∇u梯度
div A = ∇·A散度
rot A = ∇×A旋度
rot(grad u) = 0　　div(rot A) = 0

通量：∬Σ A·n dS　环量：∮L A·τ ds

斯托克斯公式

右手螺旋 
∮L P dx + Q dy + R dz
 = ∬Σ | dy dz   dz dx   dx dy |
       | ∂/∂x    ∂/∂y    ∂/∂z  |
       | P       Q       R     |

L 与曲面 Σ 满足右手螺旋。

欧拉方程

x=e^t
x²y'' + pxy' + qy = f(x)

令 x=e^t，则：

xy' = dy/dt
x²y'' = d²y/dt² − dy/dt

伯努利方程

n≠0,1
y' + P(x)y = Q(x)·yⁿ

令 z=y^(1−n)，化为一阶线性微分方程。

傅里叶级数 · 狄利克雷收敛定理

分段光滑
  • 连续点：收敛于 f(x)
  • 间断点：收敛于 [f(x⁺)+f(x⁻)] / 2
  • 端点 x=±l：收敛于 [f(−l⁺)+f(l⁻)] / 2

奇延拓 → 正弦级数；偶延拓 → 余弦级数。

空间解析几何

距离与共面

点到平面d = |Ax₀+By₀+Cz₀+D| / √(A²+B²+C²)

点到直线d = |M₀M₁ × s| / |s|

异面直线d = |M₁M₂ · (s₁×s₂)| / |s₁×s₂|

混合积 [a,b,c] = a·(b×c)；三向量共面 ⇔ 混合积 = 0。

曲面积分坑

别套二重积分的奇偶性

对坐标的曲面积分，奇偶性和二重积分不同，必须结合曲面侧判断。

04

EXAM TRAPS

通用考场避坑

四个高频混淆
01

秩相等 ≠ 向量组等价

秩相等是向量组等价的必要条件，不是充分条件。

02

矩阵等价 ≠ 向量组等价

矩阵等价 ⇔ 秩相等；矩阵等价与向量组等价不是一回事。

03

正交变换与普通合同

正交变换保长度、保特征值；普通合同变换只保惯性指数。

04

配方法系数 ≠ 特征值

配方法得到的标准形系数不一定是特征值；正交变换化标准形，系数才等于特征值。
