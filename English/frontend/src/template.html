Before you start

这张卷子，先看地图再动笔

100 分 · 180 分钟 · 五个板块 · 一套完整的时间策略

先知道每一块值多少分、该花多久，再决定考场上的做题顺序。下面的时间不是硬性规定，而是你模考后调整的起点。

这份材料怎么用

  1. 先限时做一遍。不会的词先猜，不要查；作文也要写。
  2. 再对答案。只标错题，不急着看解析，先自己找证据句。
  3. 最后拆解。用长难句和词汇库补基础，用阅读方法把“这一次”变成“下一次”。

Seven-day Plan

7 日计划：每天只做三件事

模考 → 精读 → 拆句 → 背词 → 翻译写作 → 二轮 → 复盘
