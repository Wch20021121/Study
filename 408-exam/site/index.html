BRIDGE / 01

存储层次

Cache 的 AMAT、虚拟内存的 EAT、文件系统的页缓存，本质都在回答“下一层有多慢”。

Cache ↔ 页表 → BRIDGE / 02

中断与 I/O

DMA ↔ 驱动 → BRIDGE / 03

性能三角

CPI ↔ 调度 → BRIDGE / 04
